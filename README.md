Данный проект представляет собой динамичный мультиплеерный шутер на двоих, реализованный на языке Python с использованием библиотек Pygame, CustomTkinter и Socket. Игра построена на классической архитектуре «Клиент-Сервер», где центральный узел управляет подключениями, синхронизирует действия игроков и запускает обратный отсчет перед началом боя. В основе игрового процесса лежит противостояние двух игроков на замкнутой арене с системой препятствий. Основная цель — первым набрать 3 очка, уничтожая противника точными выстрелами.

Техническая реализация включает в себя многопоточный сервер (server.py), который обрабатывает входящие TCP-соединения, присваивает уникальные ID и рассылает (broadcast) данные о перемещении, стрельбе и смертях всем участникам. Клиентская часть отвечает за рендеринг графики, обработку ввода пользователя и расчет коллизий. Одной из ключевых особенностей игры является система «Лакиблоков». При подборе бонуса игрок может получить один из девяти случайных эффектов: инверсию управления (по разным осям), существенное ускорение или замедление, временное оглушение или мощную «Ядерную пулю», которая летит быстрее и имеет увеличенный размер.

Управление в игре осуществляется клавишами W/S для движения вперед-назад, A/D для стрейфа и Q/E для поворота игрока. Огонь ведется нажатием клавиши Space, при этом в игре реализована система перезарядки боезапаса. Визуальная составляющая дополнена системой частиц для имитации взрывов и дымного следа ядерных снарядов. Протокол обмена данными использует строковые команды, такие как 'P' для передачи координат, 'B' для создания пуль и 'D' для фиксации попадания. Проект поддерживает обработку состояний игры, разделяя процесс на фазу ожидания второго игрока, фазу активного боя и финальный экран с результатами, где отображается победа или поражение. Для запуска необходимо сначала активировать сервер, а затем два экземпляра клиента. Требуется установленный Python 3 и библиотеки pygame и cutomtkinter (pip install pygame, customtkinter).
